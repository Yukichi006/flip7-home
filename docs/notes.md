## 持ち主について
- 英語が読めない。説明・メニューの文字・コメントはすべて日本語で書く
- スマホは右手で持つ。親指の届く下のほうに、よく使うものを置きたい
- 見た目は「黒い布地に白い糸のステッチ」。部品を足すときも、この雰囲気（ワッペン・縫い目・まち針・巾着・ファスナーなど）にそろえる
- 通知の印などのアクセントの色は、オレンジ（`Thread.ALERT`）だけにしている
- 直してほしいことは、スクリーンショットで送ってくる。実機を見てから細かく直す、の繰り返しで進めている

## ホーム画面の作り（0.28.0 から）
- 「片手の画面」「マス目の画面」の区別はない。どのページも同じマス目（最初は 5 列。マスの形はパッドに合わせ、行の数は画面の高さで決まる）
- 部品はどれもブロックとして、好きな場所に好きな大きさで置く。めくれるアプリのパネルも部品（`BOOK`、2×2 から）
- 持ち主の今の使い方：1 ページ目に主な情報（日付・電池・アナログ時計・再生中の曲・天気・フェーダー・アプリ一覧のウィジェット・Suica・めくれるパネル）、2 ページ目はカレンダーのウィジェットを画面いっぱいに
- 下段のポケットの口はファスナー。開き具合がアプリ一覧の開き具合とつながっている（ポケットの上の縁の線から下からせり上がる）
- 「…」の設定は、まとまりごとの一覧（0.32.0）。編集の帯は上下にずらせる
- 縫い付けメモ（0.33.0 → 0.35.0 で作り直し）：正方形の布の付箋（生成り・淡い黄・淡い桃・淡い水色）。つまんで引くと角からめくれ、引ききって離すとはがれて落ちる＝完了。長押しでいちばん前へ
- 見た目は空いているのに置けないことがあった（見えない部品がマスに残っていた）。0.35.2 で、置く前に片付け、置けなければ知らせるようにした

## ほかのアプリのウィジェット（何度も直したところ）
- 新しい作り（`android:id/background` の印があるもの。アラームなど）：余白をとらず、マスいっぱいの大きさで渡す。縮めない。小さく渡すと 2×2 で中身が出なくなる
- 古い作り（印がないもの。Suica など）：余白をとる。中身がマスより大きければ、本来の大きさで描いてから縮めて収める
- マスいっぱいに広がる作り（カレンダーなど）：中身を制限なしで測らない（測ると縮んでしまう）
- 角は Android の決まった丸み（`system_app_widget_background_radius`）で丸める。印がなければ、背景のある部品から土台を推し量る
- ウィジェットの中の一覧が指を取っても、左右のスワイプはページの切り替えに使う
- ウィジェットの中身そのものを刺繍風に描き直すことはできない（アプリが描いた絵が届くだけ）。代わりに、縁にステッチを縫える（大きさはそのまま）

## 電池の部品（0.36.0）
- 持ち主が残量を見たい機器：本体・Galaxy Buds・**Galaxy Fit3**・**スマートリング（evofit C8E7、専用アプリあり、Galaxy Ring ではない）**
- Buds は Android に残量を報告するので、そのまま読める
- Fit3 は残量を Samsung のアプリ（Galaxy Wearable）にしか送らない。標準の電池サービスを Bluetooth で直接読んでも出ない（FlipCover で試した）。
  Galaxy 標準の「バッテリー」ウィジェットには出る（本体・Fit3・Buds の順、名前は書かれず絵だけ）ので、
  0.36.0 で、電池の部品がそのウィジェットを見えないまま動かし、「%」の文字を読み取るようにした（`WidgetBattery`）。
  名前がないときは、いちばん上を本体、Android から読めている機器と同じ残量の行はその機器とみなし、残りに「つながっているのに残量の読めない機器」の名前を当てる
- リングは「バッテリー」ウィジェットに出ない。専用アプリの中だけで見える。電池サービスを読むと、成功するのに使える値が返らなかった（FlipCover のとき）。
  0.36.0 で診断（`BleInspector`）を作った。つないでサービス・読める値・通知を記録する。専用アプリが残量を問い合わせた答えを横で聞けるかもしれない。
  **結果を見てから、リングの残量の読み方を決める**。機器へ命令を書き込むのは、何が起きるか分からないので、中身が分かるまでしない
- 0.36.0 の診断の結果（リング evofit C8E7）：
  - 中身は Jieli（zhuhai_jieli）のチップ。電池サービス（180f / 2a19）はあるが、読むと空で、通知も来ない
  - 独自のサービス `be940000-7333-be46-b7ae-689e71722bd5`（be940001 書＋示、be940002 書、be940003 示）を専用アプリが使っている。
    値は `[種類][番号][全体の長さ 2 バイト LE][中身][CRC-16/CCITT-FALSE 2 バイト LE]` の包み（`RingPacket`）。届いた例：`02 26 07 00 fc 5b ee`
  - ほかに Nordic UART（6e400001）、WeChat の歩数（fee7 / fea1）、心拍（180d / 2a37）、Jieli の書き換え用らしい ae00 がある
  - 心拍（2a37）と歩数（fea1：歩数・距離・消費 kcal）は、決まった形で 1 秒ごとに届く。**新しい権限なしで歩数を出せる**（「歩数の糸巻き」の案に使える）
  - 残量の入った包みはまだ見つかっていない。0.36.1 で診断を 3 分にし、同じ値のくり返しを省き、包みを読み解いて出すようにした。
    次は、専用アプリの残量の画面を開いて記録してもらい、アプリに出ていた残量（例：80% = 0x50）の入った包みを探す
  - 0.36.1 では、専用アプリへ切り替えると FlipHome の設定パネルが閉じ、診断も一緒に止まって記録が取れなかった。
    0.36.2 で、診断と記録をパネルとは別に持つようにした（`Inspection`）。戻ってから電池の部品の設定の「調べた記録を見る」で続きを見る
  - 包み `02 26 07 00 fc 5b ee`（種類 02・番号 26・中身 fc）は、診断でつないで数秒後に毎回届く。何の知らせかはまだ分からない
- 「バッテリー」ウィジェットの作りが Samsung の更新で変わったら読めなくなる。そのときは「読み取りの様子を見る（診断）」の「ウィジェットの中身」を送ってもらう

## FlipCover（カバー画面のアプリ、github.com/Yukichi006/flip7-cover）
- **ユーザー補助（アクセシビリティ）は使わない**（持ち主の決定）。PayPay や銀行のアプリが決済を止めるため
- 「他のアプリの上に重ねて表示＋常駐」は、Google Play プロテクトに「有害なアプリ」と判定される（デバッグ版をやめても、アプリの ID を変えても同じ）
- 持ち主は不安になって、FlipCover を一度アンインストールした（5.1.1 のとき）。入れ直すなら：
  - 5.0.0：危ない許可なし。カバー画面のアイコンから開く（自動では出ない）
  - 5.1.1：重ねて表示で、閉じたら自動で出る（Play プロテクトの警告が出る）
- アプリの ID は 4.0.0 から `io.github.yukichi006.flipcover`
- 作業はブランチ `ccr-163eda99-8jh52o` で行い、ビルドが通ったら main に送ってよい（持ち主の了承済み）

## リリースと確かめ方
- `main` に push すると、GitHub Actions が正式版をビルドして Releases に出す。持ち主は Obtainium で更新する
- README だけを直して push すると、同じバージョンで出そうとしてリリースの手順が止まる（決まりどおりの止まり方で、APK には影響しない）
- テストはリポジトリの `app/src/test` にある（配置の計算・めくれるパネルの中に置く・縫い付けメモ・なぞる刺繍の外枠）。GitHub Actions が配る前に毎回動かし、落ちたらリリースも止まる（CLAUDE.md の「テスト」）
- この開発環境からは Android SDK と Google の Maven に届かないので、手元では kotlin-jvm で android-all.jar に対してコンパイルして確かめ、Robolectric でスクリーンショットを撮って見た目を確かめていた（その道具はセッションの一時フォルダにあったので、使うときは作り直す）
  - 0.36.0 のとき：Maven Central の大きいファイルは gcp.mirrors.maven.org へ飛ばされて止まる。`maven-central.storage-download.googleapis.com/maven2/` からなら取れた。
    Robolectric は androidx.test（Google の Maven にしかない）が要るので、手元では動かせなかった。画面の部品を使わないテスト（`WidgetMergeTest`）だけ手元で動かした
- 本物のウィジェット・Galaxy の動き・指の感覚は、テストでは確かめられない。実機で見てもらう
